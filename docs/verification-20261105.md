## 已知限制

- 仅支持单条消息内划选。无法获取真实模型时明确显示「模型未知」。
- 宿主 DOM 或事件协议更新需要重新核对。来源消息被删除、改写或未加载时，标记可能无法恢复。
- 草稿停止输入约 400 ms 后写入。进程在写入前突然退出，最后一次输入可能丢失。
- 图片随 JSON 存储；大笔记库会增加读取与写入开销。单次请求上限 24 MB，超大整库导出当前不能一次导回。
- 图片转为最长边 1600 px 的静态 WebP；GIF 动画不会保留。
