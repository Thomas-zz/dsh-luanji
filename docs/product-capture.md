# 乱记：对话里的随手记录

本轮实现日期：2026-11-05，插件版本 0.2.0。

## 定位

抓住一句想留下的话和当时的念头，让记录成为对话中的一个小动作。保留原项目「先留下、再理解」的思路：无需标题、分类和标签；引用不等于认同，自己的思考也不能被原话覆盖。

## 交互约定

1. 同一消息内划选，沿用 DSH 原生 text-interaction 浮动条，只出现一排：「记录 / 引用并记录 / 引用文本」。记录立即保存；引用并记录打开附有原文的浮窗；引用文本保留 DSH 原有的引用到输入框。
2. AI 引用注明消息实际使用的模型；用户引用显示「我」。同时保存会话、消息定位和文本锚点。
3. 快捷入口在侧边栏「插件」下面一行：点整行在行右侧弹出记录便签，点行尾小按钮直接进入管理页。管理页也能记录。
4. 原文与想法分别保存，合并展示。可编辑自己的想法，原文保持不变。
5. 保存成功才标记原句：淡主题色底、细下划线。删除或撤销后移除；仅未保存的引用草稿不作永久标记。
7. 引用块永远在上、自己的想法在下；划选动作用 DSH 原生浮动条呈现（floating-fill、elevation-panel、999px 圆角），不再另浮一层。
6. 保存失败保留内容并提示。重复提交同一内容使用同一记录 ID，处理服务端已保存但响应丢失的情况。

## 视觉

继承 DSH 字体、背景、边框、圆角和明暗主题；强调色使用 DSH 的深蓝静态色，不跟随品牌色的黑白反转，避免界面「灰蒙蒙」。浮窗与选区动作条用半透明毛玻璃（背景模糊 + 描边 + 阴影），管理页用卡片列表；引用块作为来源层次、位于自己的想法之前。浮窗不加遮罩、不挡对话输入区；不采用原 Web 版的纸张和书写字体。

窄窗口便签保留两侧 16 px 空隙；键盘可打开、保存、收起。动画遵循减少动态效果偏好。

## 实现

- DSH `sidebar.panellist` 注册「乱记」行（整行由外壳渲染），文档级捕获阶段监听按点击坐标分流：行尾 38px 进入 `main` 注册的管理页，其余区域打开便签；行尾小按钮是纯装饰，不嵌套交互元素。
- 划选：注册 `uiConversation.interactions` 的 `luanji` 动作，并在 `conversation.chat.text-interaction` 的 `luanji` 键渲染原生风格的浮动条；`onInteraction` 先于 DSH 自带 quote 动作打开，保证只出现一层。`引用文本` 调用原生 `inputActions.insertQuote`，没有丢掉原行为。
- `shell.overlay` 挂载便签、提示条。
- 通过消息所在的 `data-conversation-session` 与 `data-chat-node-key` 定位会话节点，避免旁侧会话和主会话串源。
- 从对应 `assistant/message` 事件的 `data.message.source.model` 读取模型，不读取当前模型选择器，也不保存内部 provider 连接标识。
- v2 `records.quoteId → quotes.id` 分离存储；API 返回合并结果供界面展示。
- CSS Custom Highlight API 绘制原句标记，不插入 span、不改写 DSH 管理的消息 DOM。记录文本位置和前后文，重渲染后重建 Range。
- 来源跳转通过 `uiWorkspace.openSession`，必要时使用会话 `loadThrough(seq)` 加载较早消息。消息删除或宿主结构变化可能导致无法定位。

## 本轮边界

本轮聚焦记录与找回，没有新增 AI 自动归档、标签推荐、云同步、关联图谱或「纸背 / 线」完整功能。原项目相关思考保留为后续方向。
