## 手机网页实测（真实浏览器，390×844 窄屏）

浏览器直连本地服务完成：

- 登录（口令错误 401 → 正确登录进入列表）；
- 新建记录 → 保存成功；
- 桌面引擎（真实 `host/sync.js`）启用同步 → 收到手机记录（rev=1）；
- 桌面新建/编辑 → 手机刷新可见（引用记录显示「AI 说的原话 · AI · DeepSeek V3.2 · 同步验证对话」完整来源）；
- 手机编辑桌面记录 → 保存成功（走同 ops 协议，baseRev=远端 rev）；
- 手机删除 → 弹窗确认 → 「已删除」+ 撤销 → 恢复成功（墓碑复活路径）；
- 搜索（正文与引用原文命中）；
- 布局度量：无横向溢出，卡片 358px 适配 390px 视口，FAB/头部正常。

实测发现并修复的真实缺陷：**页面刷新后 CSRF 令牌丢失**（此前令牌只在登录响应下发）。
修复：新增 `GET /api/web/v1/session` 恢复令牌（含测试）；静态资源改 no-cache 防止手机端
拿到旧脚本。
