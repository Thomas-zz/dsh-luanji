## 交互与布局

- 点左侧纸张图标打开全部记录；点「乱记」文字打开速记；官方右侧图钉保持宿主行为。
- 纸张图标使用独立 button，通过 portal 挂在导航主按钮旁；根据原图标位置定位，支持键盘 Enter/Space，不嵌套交互控件。
- 删除原来的行尾装饰图标、38px 点击分流和强制右内边距。
- 管理页标题、搜索常驻顶部；正文使用独立滚动容器。去掉大图标、副标题、装饰光晕和常驻输入区。
- 「记一条」展开输入；收起或 Escape 保留草稿；「继续草稿」恢复；保留快捷键保存和搜索。
- 同步状态收进顶部按钮，异常状态仍可见，设置与同步详情保持原入口功能。
- 使用原生 thin 滚动条，透明轨道；收敛卡片阴影和圆角，布局适配窄窗口。

## 第二轮修正（以本节为当前交互）

根据实际 DSH 截图反馈，撤回折叠输入区的设计，并继续缩减工具栏。

- 左侧仍为独立、可键盘操作的纸张按钮，外观沿用原行尾按钮：24px 点击区、7px 圆角、默认透明背景、悬停浅色底。
- 修复粗边框根因：按钮自身是 `[data-luanji-ui]` 根节点，原后代选择器未重置它，导致浏览器原生按钮边框露出。现显式设置 appearance、border、background、outline、box-shadow；仅键盘 focus-visible 显示焦点圈。
- 测试夹具的全局按钮重置不再覆盖该按钮，避免再次遮蔽原生样式回归。
- 管理页输入框常驻顶部，无展开、收起或「继续草稿」开关；刷新后草稿直接出现在输入框内。空输入区约 106 CSS px 高，内容增加时自动增高。
- 桌面标题、数量、搜索、同步与返回合并为一行；工具栏实测 34 CSS px 高。删除重复的「全部记录」标题行，数量处直接显示搜索匹配数。
- 保留 DSH 原生窗口控制区域所需安全间距，移除额外 12px 顶部留白。窄容器下仅搜索换行。
- 本轮 `node --check client.js`、`git diff --check` 通过。
- 隔离浏览器检查：默认输入区可见、快捷键保存后仍可继续输入、刷新恢复草稿、搜索时输入区保留、420px 无横向溢出。
- 移开鼠标后的纸张按钮计算样式：border 0px、appearance none、透明背景、outline-style none。
- 通过 Chrome 扩展截图完成浅色窄窗口视觉复核：图标无粗框，紧凑顶部与常驻输入区显示正常。Ego 截图接口仍超时；该问题未阻止这次视觉检查。
