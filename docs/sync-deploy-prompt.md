# AI 部署提示词（复制给部署 agent）

用法：把下面的提示词整段复制给服务器上可用的 AI agent（或让它 SSH 到你的服务器执行）。
发布时请把 `<仓库地址>`、`<版本 tag>` 替换为真实值——本文件与插件界面内置同一模板。

---

请根据我指定的 luanji-sync-server 仓库（`https://github.com/Thomas-zz/dsh-luanji`，版本 `<版本 tag>`）部署我的个人乱记同步服务。先读取该版本 README、`server/compose.yaml` 与 `docs/sync-protocol-v1.md`，再**只读检查**服务器 OS、Docker、磁盘、端口、域名和现有反向代理。使用独立目录、持久化数据卷和独立凭据，保持现有应用运行；不覆盖现有站点配置、不清理旧表。

配置有效 HTTPS、接口鉴权、请求限制；用管理命令（`node src/admin.mjs`）生成独立设备 Token 和手机登录口令；不在聊天或日志打印任何秘密。生成每日一致性备份与恢复说明（`docs/sync-backup-restore.md`）。

用临时测试记录验证连接、上传、拉取、重复请求幂等与鉴权失败；不读取、不上传我的真实笔记。交付：服务地址、密钥私密领取方法、手机地址、备份位置、版本、检查结果与回滚方法。

涉及尚未授权的生产变更时先展示具体改动并取得授权；缺域名或证书信息时报告缺项，不擅自关闭 TLS 校验。

---

注意事项：

- 真实同步由确定性的插件/服务代码执行，AI 只负责安装、检查、升级和排障；
- 没有 AI 的用户照 `docs/sync-deployment.md` 部署即可，两条路径产物一致；
- AI 不应接触笔记正文，也不应生成另一套协议——自己已有数据库但无同步 API 的用户，
  优先部署本配套服务，而不是让 AI 现场发明协议。
